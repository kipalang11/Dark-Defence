# 새 영웅 원본 이미지 올리는 곳

- **그림 파일만 올리면 됩니다.** png·jpg·webp 모두 되고, 파일 이름은 아무거나 괜찮습니다.
- 이름·클래스·소속·이야기·스킬·수치는 Claude가 그림을 보고 정해서 PR에 표로 적어 드립니다. 바꾸고 싶은 점은 머지 전에 말해 주세요(영웅 id는 머지 후에는 바꿀 수 없음).
- 원하는 설정이 있으면 부탁할 때 함께 적어 주세요. 적어 준 내용이 우선입니다.
- 그림 기준: `docs/art/style-guide.md` / 생성 프롬프트: `docs/art/prompt-template.md`
- 반입이 끝나면 원본은 이 폴더에서 지워집니다. 게임은 이 폴더를 읽지 않습니다.
- 처리 순서는 저장소 루트 `CLAUDE.md` / `AGENTS.md`의 '새 영웅 반입 절차'에 있습니다.
