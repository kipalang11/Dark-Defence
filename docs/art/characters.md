# 잿빛 성채 · ASHWARD — 영웅 설정 시트

`data/heroes.json`, `data/stories.json`의 내용과 `assets/<id>.webp` 일러스트를 직접 보고 정리한 설정 시트입니다.
번호는 `data/heroes.json`의 배열 인덱스(= 저장 인덱스)입니다. 새 영웅은 24번(인덱스 23)부터 맨 끝에 추가합니다.

- **대표색(UI)**: `heroes.json`의 `color` 값으로, 도감 글씨와 전투 아이콘 테두리에 쓰입니다.
- **그림 색**: 일러스트에서 실제로 넓게 쓰인 색입니다. 둘이 다르면 그림 색을 기준으로 새 그림을 맞춥니다.
- **성격**은 이야기·대사와 그림의 표정을 바탕으로 정리했습니다.

## 새 영웅 설정 시트 양식

새 영웅을 만들 때 아래 양식을 채워 이 파일 맨 끝에 추가하고, [prompt-template.md](prompt-template.md)의 빈칸에 옮겨 적습니다.

```markdown
## <번호>. <이름> `<id>`
- **클래스**: <수호자/전사/암살자/창기사/궁수/마법사/치유사/지원가>(<근접/원거리>) · <역할> / <아이콘>
- **칭호·소속**: <칭호> · <소속> (<나이>세)
- **대표색**: UI `#xxxxxx` / 그림: <주색>, <금속색 금/은>, <보조색>
- **외형 키워드**: <머리색·길이·모양>, <피부>, <눈>, <특징>, <자세>
- **의상**: <장식 갑옷 재질·문양>, <사슬 장신구>, <망토·베일>, <신발>
- **무기**: <클래스 규칙에 맞는 무기>
- **배경**: <소속 장소>, <시간대·광원>
- **성격**: <두세 단어>. <한 줄 설정>. "<대사>"
```

겹침을 피하기 위해 확인할 것: 머리색(스타일 가이드 6장), 소속(이미 있는 소속을 다시 쓰면 그 장소의 다른 구역으로 배경을 다르게), 같은 클래스 영웅의 무기 모양.
